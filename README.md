# Claude Code для 1C:EDT

Репозиторий обновлений (p2) плагина. Здесь только собранные артефакты — исходники
плагина не публикуются.

Текущая версия: **0.1.0.v20260914132738**

## Установка

1. В EDT: **Справка → Установить новое ПО…**
2. **Добавить…** → в поле «Расположение» вставьте:

   ```
   https://kaminsoft.github.io/claude-code-edt/
   ```

3. Отметьте категорию **Claude Code для 1C:EDT** и пройдите шаги мастера.
4. Перезапустите EDT.

Обновления потом приходят штатно: **Справка → Проверить наличие обновлений**.

## Если плагин раньше ставился копированием в dropins

Удалите оттуда jar, иначе в среде окажутся две одинаковые версии бандла:

```
rm <EDT>/dropins/com.kamin.edt.agent_*.jar
```

## Требования

1C:EDT 2026.1 и новее (Eclipse 4.30 / Java 17). Агент работает через Claude Code CLI,
вход в учётную запись Claude выполняется из самого чата.
